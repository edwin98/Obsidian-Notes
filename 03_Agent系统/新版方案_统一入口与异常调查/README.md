# 新版 Agent 文档：从这里开始读

这套文档讨论一个问题：**已有脚本会跑测试了，Agent 还能替工程师做什么？**

我们的答案是：测试失败以后，让它接着帮忙查。它可以换条件重跑、比较新旧版本、找出怎样才能复现、整理日志，最后把清楚的复现步骤和调查结果交给工程师。

原来的按需测试也保留。用户可以直接说：

> “帮我测一下这个版本。”

也可以说：

> “升级以后，手机移动时视频偶尔卡住，帮我查查。”

两种要求从同一个输入框进入，由系统判断接下来做什么。

## 建议先读这三篇

1. [项目总览](00_项目总览.md)：用一个例子说明系统做什么，模型和脚本分别做什么。
2. [完整案例](17_完整案例与对外讲述.md)：从用户说出问题，一直讲到复现、排查和修复验证。
3. [统一入口](11_统一入口与意图识别.md)：怎样听懂“帮我测”“继续查”“先别跑”和“现在怎么样了”。

先看这三篇，就能判断这个方向是不是你想做的。其余文档用于进一步讨论实现。

这是一套独立的新方案，还没有与原文档和代码合并。文中的故障、实验编号和结果是讲解例子，不是已经取得的项目成绩。当前进度统一写在“当前进度”那篇，其他章节集中讲清楚做法。
