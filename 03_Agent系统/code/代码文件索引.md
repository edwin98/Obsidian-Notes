# 代码文件索引

## 一、直观理解

全部入口沿“用户消息 → 意图 → 任务 → 规划 → 校验登记 → 执行 → 证据与报告”使用同一套代码。检索、统计、评测和训练围绕这条主线提供能力。

整体关系见 [系统运行全流程与交互拓扑](../18_系统运行全流程与交互拓扑.md)，阅读方法见 [学习指南](学习指南.md)。
