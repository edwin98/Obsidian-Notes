# Agent Skills 与渐进披露

集中维护文件式 Skill、资源按需加载及其与 MCP 的关系。具体宿主的命令和压缩行为应按产品版本理解。

## MCP vs Agent Skill

MCP 是能力发现与交互协议；Agent Skills 的开放格式描述任务如何做、何时使用哪些资源。Skill 可以指导调用 MCP 工具，两者位于不同层次，可以组合。

### 核心差异对比

| 维度 | MCP | Agent Skills |
| --- | --- | --- |
| 主要内容 | 工具、资源、提示词的发现与交互 | 任务步骤、适用条件和辅助资源 |
| 载体 | 协议消息及客户端/服务器实现 | SKILL.md 与可选资源目录 |
| 复用方式 | 宿主接入符合协议的服务 | 由支持该格式的 Agent 发现和加载 |
| 执行责任 | 模型提出意图，宿主/客户端执行交互 | 根据指令调用工具或使用资源；文档本身不是执行器 |

### 开放格式与渐进披露

除抽象的“能力单元”外，当前 Agent Skills 还有文件式开放格式：`SKILL.md` 提供名称、描述和正文，可附带 scripts、references、assets；通过先发现元数据，再加载正文与所需资源进行渐进披露。[官方格式说明](https://agentskills.io/home)

MCP 定义能力如何接入与交互，Skill 描述任务如何做、何时使用哪些资源。Skill 可以指导使用 MCP 工具，因此二者是不同层次、可以组合，不宜理解为两种互斥工具调用机制。

MCP 支持哪些能力、Skill 如何触发与加载，仍取决于具体宿主实现；不能统一断言 Skill 就是函数、只能单 Agent 复用或必然与某个 slash command 等价。

## Skill 的渐进披露机制与长上下文处理

### 渐进披露（Progressive Disclosure）是什么

Agent Skills 先暴露名称、描述等元数据，命中适用场景后加载 SKILL.md 正文，再按需读取 scripts、references、assets。这样减少未使用资源占用上下文。[官方开放格式](https://agentskills.io/home)

触发方式、正文在会话中的保留和压缩由宿主决定；不应统一断言执行后指令就从上下文消失，也不能将所有 Skill 等同于某个产品的 slash command。

### 长代码的上下文控制策略

在 Skill 执行过程中，若需要阅读较长的代码文件，主要有以下几种处理方式：

#### 1. 分段读取（offset + limit）

不要一次读整个文件，用 `Read` 工具的 `offset`/`limit` 参数按需分段：

```
先读文件头部了解结构 → 定位关键函数行号 → 只读目标段落
```

实际操作：先读前 50 行看结构，再用 `Grep` 定位具体函数，再用 `Read(offset=N, limit=50)` 只读那段。

#### 2. 用 Grep 替代全文阅读

能搜索定位的就不要全文读，`Grep` 只返回匹配行及上下文（`-C N`），消耗的 token 远少于整个文件。

#### 3. 子 Agent（隔离上下文）

用 `Agent` 工具将"读大文件、做分析"的工作委托给子 Agent：

- 子 Agent 有独立的 context window，不污染主对话
- 子 Agent 返回**摘要结果**而非原始代码，主对话只消耗摘要 token
- 适合场景：分析一个 500 行的类、理解一个模块的所有导出等

```
主 Agent → [Agent tool] → 子 Agent 读/分析大文件 → 返回 200 字摘要 → 主 Agent 继续
```

#### 4. 对话自动压缩

Claude Code 会自动压缩历史消息（conversation compaction），当 context 接近上限时，将早期消息压缩为摘要，保留最近的工作状态。这是系统级兜底，不需要手动触发。

#### 5. 最佳实践总结

| 场景                | 推荐方式                            |
| ----------------- | ------------------------------- |
| 需要了解文件整体结构        | Read 前 50-100 行 + Grep 关键词      |
| 需要读某个函数实现         | Grep 定位行号 → Read(offset, limit) |
| 需要分析整个模块          | 委托子 Agent，只要摘要                  |
| 代码超过 ~300 行且需全文理解 | 子 Agent + 摘要回传                  |
| 历史对话太长影响当前任务      | /clear 重开，或依赖自动压缩               |
