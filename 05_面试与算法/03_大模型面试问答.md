# 大模型面试问答

面试复习页：先口述短答，再进入正文解释机制、例子与失败模式。项目数字和配置只引用 [[02_RAG系统/01_项目事实与实现状态]]、[[03_Agent系统/01_项目事实与实现状态]]，不在本页复制一套未经确认的数值。

## 微调时的数据量级在什么级别？如何构造的？有没有使用模型蒸馏？

**短答**：按任务列数据来源、标注标准、过滤与隔离，再说明样本量和蒸馏方式。合成 QA、实际训练对与候选标注文档对的数量分别统计；本项目数字和最终配置仍需日志确认。

**追问**：合成 QA 如何避免假正样本与训练测试泄漏？

**正文**：[[02_RAG系统/08_Embedding领域微调]]。

## 简单介绍一下 LoRA 微调：LoRA 微调时参数初始化用的什么方法？如何评估微调的模型达到了预期效果？

**短答**：LoRA 冻结基座，以低秩更新适配目标模块；初始化、缩放与是否量化取决于具体方法。分别评估领域任务、结构格式与通用能力保留，不能只看训练 loss。

**追问**：LoRA 可训练参数减少为什么不等于总显存同比减少？

**正文**：[[01_大模型/02_训练与对齐/01_SFT与参数高效微调]]。

## 不同的应用场景是训练不同模型吗？还是说就训练了一个模型呢？

**短答**：可使用独立模型、多任务同一模型或共享基座加多适配器。按任务差异、数据量、部署成本与负迁移比较，而不是按每个场景机械拆模型。

**追问**：如何发现多任务之间的负迁移？

**正文**：[[01_大模型/02_训练与对齐/01_SFT与参数高效微调]]。

## 什么叫拒绝采样？

**短答**：为同一输入生成候选，再通过规则、执行或可靠裁判筛选合格样本。筛选器本身要验证，并记录采样与保留分布，避免只留下同一类容易样本。

**追问**：拒绝采样与偏好数据构建有何不同？

**正文**：[[01_大模型/02_训练与对齐/01_SFT与参数高效微调]]。

## 讲一下 DeepSeek 训练一个 Step 的流程。

**短答**：先区分预训练、SFT 与 RL。在线 RL 的一步通常包含 rollout、奖励与优势计算、策略更新；具体 old/reference 策略、裁剪和同步方式取决于算法实现。

**追问**：采样策略陈旧会带来什么问题？

**正文**：[[01_大模型/02_训练与对齐/02_偏好对齐算法_PPO_DPO_GRPO]]。

## Tokenize 用的分词算法有哪些？BBPE 为什么使用 Unicode 编码？

**短答**：Tokenizer 将文本编码为模型词表中的 ID。BPE 等算法的合并单位和输入表示各有区别，BBPE 使用字节表示并配套可逆映射；它与普通中文分词不是同一个问题。

**追问**：字节、Unicode 字符与 token 为什么不是一一对应？

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制]]。

## 结构、格式与业务正确性如何分别保证？

**短答**：JSON 可解析、Schema 合法、业务值正确分层保证。原生约束或约束解码控制结构，应用校验数值关系和权限；拒绝、截断和工具失败分别处理。

**追问**：修复后的 JSON 为什么仍不能直接执行？

**正文**：[[01_大模型/03_推理与接口/02_结构化输出与校验]]。

## Query 进入大模型后的流程是怎样的？怎么判断模型输出是否结束？了解自回归生成吗？

**短答**：输入经过模板与 Tokenizer 编码，Prefill 处理已有上下文，Decode 自回归产生后续 token；按 EOS、停止条件或输出预算结束。KV Cache 与训练激活分别计算。

**追问**：Prefill 与 Decode 的主要瓶颈有何区别？

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制]]。

## 大模型调用时有哪些参数（比如温度、top_p、惩罚系数等）？

**短答**：温度与 top_p/top_k 影响采样分布，重复惩罚影响已生成 token，最大输出和 stop 控制结束。参数支持依提供方而异，降低随机性不保证事实正确。

**追问**：结构化数据为何不能只靠低 temperature 保证？

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制]]。

## MoE 与混合注意力的成本如何估算？

**短答**：区分总权重驻留、每 token 激活专家、注意力 KV 与循环层状态，再按精度、分片和长度估算。只看激活参数不能推导部署显存。

**追问**：MoE 节省计算时可能增加哪些通信成本？

**正文**：[[01_大模型/01_模型结构/03_MoE混合专家模型]]。

## 不同推理加速机制解决什么瓶颈？

**短答**：PagedAttention 管 KV 内存组织，prefix caching 复用前缀，chunked prefill 调度长输入，推测解码验证候选，P/D 分离还增加 KV 传输。先定位瓶颈再比较有效吞吐。

**追问**：为什么某种加速在高并发时可能收益下降？

**正文**：[[01_大模型/03_推理与接口/03_vLLM与推理优化]]。

## 显式 CoT 与内置推理预算有什么区别？

**短答**：显式 CoT 是输出中间步骤的提示策略；内置推理模型可能通过独立推理控制工作。预算、输出长度和最终解释并非同一设置，必须按接口支持范围理解。

**追问**：如何同时检查质量、时延与总成本？

**正文**：[[01_大模型/03_推理与接口/01_提示词与推理策略]]。

## 讲一讲你对 GRPO 的理解。

**短答**：对同一问题采样一组回答，用组内奖励统计量构造相对优势，省去独立 Critic；仍需 rollout、奖励与策略更新，关注长度偏差和验证器漏洞。

**追问**：组内奖励全部相同时如何处理？

**正文**：[[01_大模型/02_训练与对齐/02_偏好对齐算法_PPO_DPO_GRPO]]。

## DPO 和 PPO 算法有什么区别？为什么 DPO 容易出现模型退化？

**短答**：DPO 以离线偏好对直接优化策略，PPO 使用采样和奖励形成在线更新。DPO 的质量依赖数据、参考模型、训练强度与分布覆盖，不能由单一超参数保证不退化。

**追问**：如何发现提高偏好分差却损失任务能力？

**正文**：[[01_大模型/02_训练与对齐/02_偏好对齐算法_PPO_DPO_GRPO]]。

## DeepSeek-R1 论文有看过吗？它在模型架构层面、算法层面有什么创新？

**短答**：区分继承自 V3 的架构与 R1 后训练配方。R1 包括冷启动、推理 RL、拒绝采样混合 SFT 和后续全场景 RL；R1-Zero 是不同实验路线。

**追问**：为什么可验证奖励仍然可能被利用？

**正文**：[[01_大模型/02_训练与对齐/02_偏好对齐算法_PPO_DPO_GRPO]]。

## GRPO 后续算法分别解决什么问题？

**短答**：按解决的问题理解：采样有效性、长度与难度偏差、token/序列级优化及 off-policy 稳定性。方法名称与库里某个 loss 开关不等于完整训练配方。

**追问**：用什么同条件实验比较这些方法？

**正文**：[[01_大模型/02_训练与对齐/02_偏好对齐算法_PPO_DPO_GRPO]]。

## MTP 怎样实现，和推测解码有什么关系？

**短答**：训练中加入未来 token 预测目标；具体模型可用预测头或递归模块等结构。推理加速还需候选验证与合适实现，不能把训练目标等同于无条件并行生成。

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制]]。

## 4B 微调显存怎样估算，KV Cache 占多少？

**短答**：拆分权重、梯度、主权重、优化器、激活和临时空间，再说明精度、分片与 offload。常规 teacher-forcing SFT 的激活与生成 KV Cache 分开计算。

**正文**：[[01_大模型/02_训练与对齐/03_DeepSpeed与显存估算]]。

## Qwen3 的 RMSNorm 放在哪里？

**短答**：按具体 Qwen3 实现区分 block 内 Pre-RMSNorm、Attention 内 Q/K Norm 与输出 Norm；不要再加一个假定的 Embedding 后独立 Norm。

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制]]。

## System/User/Tool 消息与 Prompt 是什么关系？

**短答**：消息是接口的数据结构，模板将其组织为模型输入；系统指令、用户问题和工具返回各用其对应角色。工具输出不能为了动态内容统一改成 user。

**正文**：[[03_Agent系统/03_Function-Calling与消息协议]]。
