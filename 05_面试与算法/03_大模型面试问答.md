# 大模型面试问答

面试复习页：先口述短答，再进入正文解释机制、例子与失败模式。项目数字和配置只引用 [[02_RAG系统/01_项目事实与实现状态]]、[[03_Agent系统/01_项目事实与实现状态]]，不在本页复制一套未经确认的数值。

前 19 题为 Transformer 基础八股，原理统一见 [[01_大模型/01_模型结构/01_Transformer与生成机制#Transformer 基础]]。

## Transformer 的整体结构是怎样的？Encoder 和 Decoder 有什么区别？

**短答**：原始结构是 Encoder-Decoder。Encoder 每层为双向自注意力 + FFN；Decoder 每层为因果掩码自注意力 + 交叉注意力 + FFN，交叉注意力的 Q 来自 Decoder、K/V 来自 Encoder 输出。每个子层都有残差与 LayerNorm，输入为 Embedding 加位置编码。

**追问**：交叉注意力的 K/V 在生成时需要每步重算吗？（不需要，Encoder 输出固定，可一次计算后缓存。）

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制#整体架构与三种变体]]。

## 写出 Self-Attention 公式，为什么要除以 √d_k？

**短答**：$\text{softmax}(QK^\top/\sqrt{d_k})V$。若 q、k 各分量独立、均值 0、方差 1，点积方差为 $d_k$，数值过大会使 Softmax 饱和、梯度接近 0；除以 $\sqrt{d_k}$ 把方差拉回 1。

**追问**：为什么不除以 $d_k$？（会把方差缩到 $1/d_k$，分布过于平滑，注意力区分度下降。）

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制#缩放点积注意力]]。

## 为什么 Q、K 要用不同的投影矩阵？能不能直接用 X 自己做点积？

**短答**：共用矩阵会让注意力矩阵对称，A 对 B 与 B 对 A 的关注度被强制相等，且 token 倾向于最关注自己；分开投影让查询与被查询处在不同空间，表达能力更强。

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制#缩放点积注意力]]。

## 为什么用多头注意力？多头比单头计算量更大吗？

**短答**：多个头在不同子空间学习不同关系（依存、指代、局部邻近等），类似多通道。每头维度为 $d_{model}/h$，总参数量与 FLOPs 与单头全维注意力基本相同。

**追问**：头数越多越好吗？（单头维度过小会削弱表达；训练后很多头可剪枝。）

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制#多头注意力]]。

## Transformer 中有哪些 Mask？分别起什么作用？

**短答**：Padding Mask 屏蔽补齐位置；Causal Mask 把上三角置为 $-\infty$，让位置 t 只看 ≤t 的 token，使训练时能一次前向并行计算所有位置的 loss 而不泄露未来信息。

**追问**：为什么填 $-\infty$ 而不是 0？（Mask 加在 Softmax 之前，填 0 后 $e^0=1$ 仍有权重。）

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制#掩码机制]]。

## FFN 的作用是什么？为什么大模型用 SwiGLU？

**短答**：Attention 负责 token 间信息交换，FFN 对每个 token 独立做非线性变换，被认为存储大量知识，约占每层 2/3 参数。SwiGLU 用门控结构动态筛选信息，效果优于 ReLU/GELU；因有三个矩阵，$d_{ff}$ 取约 $\frac{8}{3}d$ 以保持参数量。

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制#前馈网络与激活函数]]。

## 为什么用 LayerNorm 而不用 BatchNorm？

**短答**：序列长度可变且有 padding，按 batch 统计不稳定；BN 依赖 batch 统计量，小 batch 和推理时训练推理不一致；LN 在每个 token 的特征维度上归一化，与 batch 和长度无关。

**追问**：RMSNorm 比 LayerNorm 少了什么？（去掉均值中心化和 bias，只按均方根缩放。）

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制#残差连接与归一化]]、[[01_大模型/01_模型结构/01_Transformer与生成机制#使用 RMSNorm 而非 LayerNorm]]。

## Pre-Norm 和 Post-Norm 有什么区别？

**短答**：Post-Norm 先加残差再 Norm（原始 Transformer、BERT），Pre-Norm 先 Norm 再进子层、残差直通（GPT-2、Llama、Qwen）。Pre-Norm 恒等路径更干净，深层训练更稳定、对 warmup 不敏感；Post-Norm 调好后可能效果更好，但深层易发散。

**追问**：有没有兼顾两者的方案？（如 DeepNorm 缩放残差、Sandwich-Norm 等。）

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制#Pre-Norm 架构]]。

## 残差连接起什么作用？

**短答**：为梯度提供恒等直通路径，缓解深层网络的梯度消失和退化，使堆叠几十上百层成为可能；也让每层只需学习对表示的增量修正。

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制#残差连接与归一化]]。

## Transformer 为什么需要位置编码？有哪些方式？

**短答**：自注意力对输入顺序是置换等变的，不加位置信息就无法区分词序。方式包括可学习绝对位置、Sinusoidal、相对位置、RoPE（旋转 Q/K）和 ALiBi（注意力偏置）；当前主流是 RoPE，配合 YaRN 等做长度外推。

**正文**：[[01_大模型/01_模型结构/02_位置编码与上下文扩展]]。

## Self-Attention 的时间与空间复杂度是多少？长序列怎么优化？

**短答**：$QK^\top$ 与加权 $V$ 为 $O(n^2d)$，注意力矩阵显存 $O(n^2)$；投影与 FFN 为 $O(nd^2)$。优化方向：FlashAttention（精确计算、减少显存读写）、稀疏/滑动窗口注意力、线性注意力，以及混合架构。

**追问**：FlashAttention 降低了计算复杂度吗？（没有，FLOPs 仍为 $O(n^2)$，降低的是 HBM 访存与显存占用。）

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制#参数量与计算复杂度]]。

## 如何估算一个 Transformer 的参数量和训练 FLOPs？

**短答**：每层 Attention $4d^2$ + FFN $8d^2$ ≈ $12d^2$，总参数 ≈ $12Ld^2+Vd$。训练 FLOPs 约为 $6N \times$ token 数（前向 $2N$、反向 $4N$）。可以用 Llama-7B 现场验算得到约 6.7B。

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制#参数量与计算复杂度]]、[[01_大模型/02_训练与对齐/03_DeepSpeed与显存估算]]。

## 什么是 KV Cache？MQA、GQA、MLA 有什么区别？

**短答**：自回归时缓存历史 token 的 K/V，避免重复计算，代价是显存随长度线性增长。MQA 所有头共享一组 K/V；GQA 按组共享，在质量与显存间折中；MLA 将 K/V 压缩为低秩潜向量缓存。Decode 受显存带宽限制，KV 越小吞吐越高。

**追问**：为什么只缓存 K/V 不缓存 Q？（历史位置的 Q 在后续步骤中不再使用，只有新 token 的 Q 需要和全部 K/V 交互。）

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制#KV Cache 与 MQA、GQA、MLA]]。

## BERT 和 GPT 有什么区别？为什么现在主流是 Decoder-only？

**短答**：BERT 是 Encoder-only、双向注意力、MLM 预训练，擅长理解与 Embedding；GPT 是 Decoder-only、因果注意力、Next Token Prediction，擅长生成。Decoder-only 训练信号更密、训练与生成一致、支持 In-Context Learning、可直接复用 KV Cache，且 Scaling 经验好。

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制#整体架构与三种变体]]。

## Transformer 相比 RNN/LSTM 的优势和劣势？

**短答**：优势是训练可并行、任意两位置路径长度为 1、长依赖建模好、易于扩展；劣势是注意力复杂度随长度平方增长、推理需维护 KV Cache、本身缺少位置归纳偏置。

**追问**：Mamba 等线性 RNN/SSM 为什么又被重新关注？（推理状态大小固定、长序列成本线性，常与注意力层混合使用。）

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制#参数量与计算复杂度]]、[[01_大模型/01_模型结构/03_MoE混合专家模型#2.3 混合注意力与状态缓存]]。

## 训练时 Decoder 可以并行，推理时为什么不行？什么是 Exposure Bias？

**短答**：训练用 Teacher Forcing，真实序列已知，配合因果掩码可一次前向算出所有位置；推理时下一 token 依赖上一步输出，只能逐步生成（Prefill 可并行）。训练中模型从未见过自己的错误，推理时错误累积，即 Exposure Bias。

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制#训练与推理的差异]]。

## Embedding 为什么要乘 √d_model？什么是权重共享？

**短答**：原论文 Embedding 与输出层共享权重，初始化较小，乘 $\sqrt{d_{model}}$ 使其量级与位置编码相当，避免位置信息淹没语义。权重共享指输入 Embedding 与 LM Head 用同一矩阵，节省 $Vd$ 参数；词表大、参数少的小模型常共享，大模型多数不共享。

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制#整体架构与三种变体]]。

## Transformer 中 Dropout 用在哪里？

**短答**：原论文用于 Embedding 与位置编码相加后、每个子层输出加残差之前，以及注意力 Softmax 后的权重上。大规模预训练数据充足，很多现代大模型预训练时把 Dropout 设为 0。

## 手写一个 Multi-Head Attention。

**短答**：线性投影得到 Q/K/V → reshape 为 `(B, h, T, d_k)` → $QK^\top/\sqrt{d_k}$ → 加因果掩码 → Softmax → 乘 V → 转置拼接 → 输出投影。要能说出每步形状和掩码填 $-\infty$ 的原因。

**正文**：[[01_大模型/01_模型结构/01_Transformer与生成机制#极简实现]]。

**短答**：LoRA 冻结基座，以低秩更新适配目标模块；初始化、缩放与是否量化取决于具体方法。分别评估领域任务、结构格式与通用能力保留，不能只看训练 loss。

## 显式 CoT 与内置推理预算有什么区别？

**短答**：“Let's think step by step” 是推理时的提示策略；现代推理模型还通过推理轨迹 SFT、可验证奖励 RL 或蒸馏学习推理行为。运行时仍可能先生成额外推理 token，再给出答案。能力进入权重不等于省去运行时推理；预算、答案长度和可见解释也不是同一概念。
